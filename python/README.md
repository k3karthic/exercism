## Init

```bash
uv init
```

## Run

```bash
uv run python index.py
```

## Format

```bash
make format
```

## Test coverage

```bash
make coverage
```

Prints a coverage summary with missing lines and writes
`coverage/coverage-final.json`.

```bash
make lint
```

```bash
make scan
```

## Check cognitive complexity

```bash
make complexity
```

## Find unused code

```bash
make vulture
```
